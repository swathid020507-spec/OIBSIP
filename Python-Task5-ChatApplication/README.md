Task 5 – Chat Application

Project Description

The Python Chat Application is a client-server messaging system that allows multiple users to connect to a server and exchange messages in real time.

Features

- Multiple clients can connect to the chat server.
- Users can enter their usernames.
- Messages are shared with other connected users.
- Notifications appear when users join or leave.
- Users can leave the chat by typing "/quit".
- Handles connection errors and client disconnections.

Technologies Used

- Python 3
- Socket Programming
- Multithreading
- TCP/IP Networking

Requirements

- Python 3 installed on your computer.
- No additional Python libraries are required.

How to Run

Step 1: Start the server

Open a terminal in the project folder and run:

python server.py

Keep the server running.

Step 2: Connect the first client

Open a second terminal and run:

python client.py

Enter a username when prompted.

Step 3: Connect another client

Open a third terminal and run:

python client.py

Enter a different username.

Step 4: Exchange messages

Type messages in either client terminal to send them to the other connected users.

Type "/quit" to leave the chat.
