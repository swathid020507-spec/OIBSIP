Project Description

This project is a command-line Random Password Generator developed using Python. It allows users to generate passwords of their chosen length with different character types.

Features

- Generates passwords with a minimum length of 8 characters
- Supports lowercase letters
- Supports uppercase letters
- Supports numbers
- Supports special characters
- Allows users to select their preferred character types
- Validates password length and user choices
- Handles invalid numeric input
- Allows users to generate another password

Technologies Used

- Python
- random module
- string module

How to Run

1. Install Python on your computer.
2. Open this project folder in Visual Studio Code.
3. Open "main.py".
4. Open the VS Code terminal.
5. Run the following command:

python main.py

6. Enter a password length of at least 8.
7. Select the character types using options 1, 2, 3, and 4.
8. View the generated password.
