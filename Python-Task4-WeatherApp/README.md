Task 4 – Weather App

Project Description

The Python Weather App fetches current weather information for a city entered by the user using the free wttr.in weather service.

Features

- Search weather by city name
- Display current temperature in Celsius
- Show feels-like temperature
- Display weather conditions
- Show humidity percentage
- Display wind speed
- Handle network errors and invalid responses
- Check weather for multiple cities

Technologies Used

- Python
- Requests library
- wttr.in weather service

Requirements

- Python 3
- Requests library
- Internet connection

Installation

Install the required library:

python -m pip install requests

How to Run

Run the following command from the project folder:

python main.py

Enter a city name when prompted, for example, Chennai. The application will display its current weather information.
