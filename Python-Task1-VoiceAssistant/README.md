Task 1 - Voice Assistant

Project Description

This project is a simple voice assistant developed using Python. It listens to voice commands through the microphone, recognizes speech, and responds using text-to-speech.

Features

- Responds to greetings
- Announces the current time and date
- Opens Google and YouTube
- Searches Google using voice commands
- Handles unrecognized speech and microphone timeouts
- Supports voice commands to exit the program

Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3

How to Run

1. Install Python.

2. Install the required libraries:
   
   "python -m pip install SpeechRecognition pyttsx3 PyAudio"

3. Open the project folder in VS Code.

4. Run the program:
   
   "python main.py"

5. Allow microphone access and speak a command.

6. Say "Exit" to stop the assistant.

Sample Voice Commands

- Hello
- What time is it?
- What is the date?
- Open Google
- Open YouTube
- Search Python tutorials
- Exit
